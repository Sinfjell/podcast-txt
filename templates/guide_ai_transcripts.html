Podcast transcripts in ChatGPT and Claude

Connect Podskrift to ChatGPT or Claude and you can ask for any podcast episode by name: “Summarise the latest episode of Lenny's Podcast.” Your AI finds the show and the episode through Podskrift, Podskrift transcribes the audio, and the chat writes the summary. It also works in Cursor, VS Code and Claude Code.

Transcription uses your Podskrift minutes. {% if trial_minutes %} New accounts get {{ trial_minutes }} free minutes, and {% endif %} episodes you've already transcribed cost nothing to fetch again.

How it works

Podskrift adds four tools to your AI. You don't need to name them. Just ask in plain language.

ToolWhat it does
search_podcastsFinds a show by name
list_episodesLists a show's recent episodes
get_transcriptReturns the transcript, or starts transcription and shows the cost in minutes
get_transcript_statusChecks a running job until the text is ready

Before a new transcription starts, your AI sees what it costs and how many minutes you'll have left. A one-hour episode takes a few minutes. If you don't have enough minutes, nothing starts, and you get a link to buy more.

Podskrift only makes the transcript. The summary, translation or Q&A comes from your chat app, in whatever style you ask for.

Connect Podskrift to ChatGPT

  1. Go to chatgpt.com/plugins, select +, then Add custom MCP server.
  2. Name it Podskrift and enter {{ mcp_connector_url }}.
  3. Choose OAuth, accept the risk warning, and select Create as a plugin.
  4. Log in to Podskrift and click Allow.
  5. In a new chat, type @Podskrift or just ask for an episode.

Screenshots and a tighter walkthrough: Connect Podskrift to ChatGPT. Availability: custom MCP servers depend on your ChatGPT plan and workspace. OpenAI currently lists full MCP support as a beta for Business, Enterprise and Edu. Pro can connect MCP servers with read/fetch permissions, and Free and Go don't have plugin extensions. MCP apps work on the web, not in the mobile app. In a Business or Enterprise workspace, an admin has to allow custom MCP servers. On some personal accounts, the option only appears after you turn on Developer mode under Settings → Security and login. Sources: OpenAI: connect an MCP server · OpenAI Help: developer mode and MCP apps.

Connect Podskrift to Claude (claude.ai and Desktop)

  1. Go to Customize → Connectors.
  2. Click + Add, then Add custom connector.
  3. Name it Podskrift, paste {{ mcp_connector_url }}, and click Continue.
  4. Review the detected OAuth settings and keep sign-in enabled. Finish adding it, then click Connect. Log in to Podskrift and click Allow.

Fuller walkthrough: Connect Podskrift to Claude. Custom connectors work on Claude Free (one connector), Pro, Max, Team and Enterprise, and in Claude Desktop on the same account. On Team and Enterprise, an Owner adds the connector under Organization settings → Connectors first. Source: Anthropic: custom connectors using remote MCP.

Connect Cursor, VS Code or Claude Code

Use the URL and sign in, or create an API key under Settings and send it as a header.

  • Claude Code: claude mcp add --transport http podskrift {{ mcp_connector_url }}, then run /mcp to sign in.
  • Cursor: add {{ mcp_connector_url }} to ~/.cursor/mcp.json, optionally with "headers": { "Authorization": "Bearer psk_…" }.
  • VS Code: run MCP: Add Server, choose HTTP and enter {{ mcp_connector_url }}.

Full configuration examples are in the API docs.
