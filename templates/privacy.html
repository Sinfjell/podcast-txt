Privacy

Podskrift stores your account email, password hash, optional OpenAI API key, and transcripts you create. Your OpenAI key is used only to call OpenAI on your behalf; we never send it to analytics.

We use PostHog (EU Cloud) for product analytics and session replay so we can see where signup-to-first-transcript drops off. Replays mask form inputs (including email, password, and API key fields). We identify you only by an internal user id — not by email or name — and we do not send API keys, passwords, emails, or transcript text as event properties.
