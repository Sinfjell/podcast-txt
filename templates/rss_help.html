Finding RSS Feeds

The easy way

Just use the search bar on the home page. Type the podcast name and we'll find the feed for you.

Go to search

Manual methods

Apple Podcasts

Copy the podcast URL, paste it in our search — we convert Apple URLs automatically.

Spotify

Spotify doesn't expose RSS feeds. Use the search bar instead — it finds the same podcast via iTunes.

Direct RSS

If you have the RSS URL (from the podcast's website), paste it directly in the search box on the home page.

What you need

An OpenAI API key. Transcription uses the Whisper API — you pay OpenAI directly at ~$0.006/minute of audio. A typical 1-hour episode costs about $0.36.
