Customer API

Find an episode, transcribe it and fetch the transcript from your own scripts or agents. {% if trial_minutes %} API jobs draw on the same {{ trial_minutes }} free trial minutes as the website; after that, add your own OpenAI API key in Settings. {% else %} Transcription runs on the OpenAI API key saved in your Settings. {% endif %}

1. Get a key

Create one in Settings → API key. Keys start with psk_, one per account, and the full key is shown once. Regenerate or Revoke there — the old key stops working immediately.

Send it as Authorization: Bearer psk_… or X-Api-Key: psk_…. Keep it out of source control.

2. Resolve → transcribe → transcript
export PODSKRIFT_API_KEY='psk_…'   # from Settings — never commit

# Resolve an episode
curl -sS -H "Authorization: Bearer $PODSKRIFT_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"publisher":"Spårtsklubben","date":"2026-09-10"}' \
  https://podskrift.com/api/v1/resolve

# Start transcription (same trial path as the UI)
START=$(curl -sS -H "Authorization: Bearer $PODSKRIFT_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"publisher":"Spårtsklubben","date":"2026-09-10"}' \
  https://podskrift.com/api/v1/transcriptions)
ID=$(python3 -c "import json,sys; print(json.load(sys.stdin)['id'])" <<<"$START")

# Poll
curl -sS -H "Authorization: Bearer $PODSKRIFT_API_KEY" \
  "https://podskrift.com/api/v1/episodes/$ID"

# Transcript when ready
curl -sS -H "Authorization: Bearer $PODSKRIFT_API_KEY" \
  "https://podskrift.com/api/v1/episodes/$ID/transcript"

date is YYYY-MM-DD in Europe/Oslo. Poll until transcript_status is ready; add ?format=srt to the transcript URL for subtitles.

Endpoints
  • POST/GET /api/v1/resolve — find an episode by publisher + date, or by URL
  • POST /api/v1/transcriptions — start a transcription (reuses an existing job for the same episode)
  • GET /api/v1/episodes — your transcribed episodes, by publisher and/or date
  • GET /api/v1/episodes/<id> — one job and its transcript_status
  • GET /api/v1/episodes/<id>/transcript — the text, once ready
Status codes
StatusMeaning
401Missing, wrong or revoked key
402Free trial used up — add your own OpenAI API key in Settings
404Not found (or another account’s job)
