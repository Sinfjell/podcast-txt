Use Podskrift in ChatGPT and Claude

Ask your AI to summarise, quote or search a podcast episode — Podskrift fetches or transcribes it for you.

MCP connects your AI app to Podskrift, so it can find episodes and read transcripts for you. Choose your app for the full walkthrough, or copy the URL below if you already know the setup.

Ask your AI

“Summarise the latest episode of Hard Fork”

How to connect

Copy the connector URL

Your app needs this address to reach Podskrift.

{{ mcp_connector_url }}

Add it as a connector in your app

Paste the URL where your app asks for an MCP server. Steps for each app are below.

Sign in to Podskrift

Approve access when prompted. Transcription uses the same minutes as the website.

Per app

  1. Go to chatgpt.com/plugins, select +, then Add custom MCP server.
  2. Name it Podskrift and enter {{ mcp_connector_url }}.
  3. Choose OAuth, accept the risk warning, and select Create as a plugin.
  4. Log in to Podskrift and click Allow, then ask for an episode in a new chat.

Full MCP is a beta for Business, Enterprise and Edu. Pro can connect with read/fetch. Free and Go don’t have plugin extensions. Web only — not the mobile app. Business/Enterprise may need an admin to allow custom MCP servers; some personal accounts need Developer mode under Settings → Security and login. Sources: Connect an MCP server · Developer mode and MCP apps. Full ChatGPT guide with screenshots.

  1. Open Claude Connectors, then + Add → Add custom connector.
  2. Name it Podskrift, paste {{ mcp_connector_url }}, and continue.
  3. Click Continue, review the detected OAuth settings, and keep sign-in enabled. Finish adding it, then Connect — log in to Podskrift and click Allow.

Works on Claude Free (one connector), Pro, Max, Team and Enterprise, and in Claude Desktop. On Team/Enterprise an Owner adds it under Organization settings → Connectors first. Source: Claude custom connectors. Full Claude guide.

  1. In Cursor, open Settings → MCP, or edit ~/.cursor/mcp.json (project: .cursor/mcp.json). In VS Code, use MCP settings or your workspace MCP config.
  2. Add a remote server with URL {{ mcp_connector_url }} — no API key required when OAuth is available.
  3. Save, enable the server, and complete Podskrift sign-in in the browser when prompted.
{
  "mcpServers": {
    "podskrift": {
      "url": "{{ mcp_connector_url }}"
    }
  }
}

You can still use a Podskrift API key in a Bearer header instead — see API docs.

  1. In a terminal (outside a Claude Code session), add the remote HTTP server:
claude mcp add --transport http podskrift {{ mcp_connector_url }}
  1. Start Claude Code and complete Podskrift sign-in when prompted.
  2. Ask for a show or episode — tools appear under the podskrift server name.

Use --scope user to register it for all projects. Docs: Claude Code MCP.
