Set it up

  1. Open Customize, then Plugins

    In ChatGPT on the web, open chatgpt.com/plugins — or click the Customize icon in the sidebar, then choose Plugins.

    {% if shots.get('01-customize-plugins') %} {% endif %}

  2. Add a custom MCP server

    Click Add, then choose Add custom MCP server.

    {% if shots.get('02-add-custom-mcp-server') %} {% endif %}

  3. Fill in Podskrift and create the plugin

    Name: Podskrift. Server URL: {{ mcp_connector_url }}. Authentication: OAuth. Tick I understand and want to continue, then click Create as a plugin.

    {{ snippet(mcp_connector_url, copy_label='Copy', what='connector URL') }} {% if shots.get('03-create-as-plugin') %} {% endif %}

  4. Sign in to Podskrift and Allow

    ChatGPT opens Podskrift’s sign-in. Log in (or create an account), then click Allow. Transcription uses the same minutes as the website.

  5. Try it in a new chat

    Ask for an episode in plain language — for example:

    {{ snippet("Summarise the latest episode of Hard Fork", copy_label='Copy', what='prompt') }}

Check that it worked

Podskrift should appear as connected in your app. In a new chat, enable Podskrift from the tools menu. Ask “Use Podskrift to find the latest episode of Hard Fork.” Look for a Podskrift tool call, then ask for a summary or a quote with timestamps.

If the reply says it cannot access podcasts, check that Podskrift is enabled in this conversation. A long episode may need time to transcribe; ask your AI to check the transcription status before summarising.

What it costs

Uses your Podskrift minutes (trial, credit pack, or your own OpenAI key). Episodes you've already transcribed are free to fetch again on your account. Full pricing.

Troubleshooting

  • Sign-in loop — Finish Allow in the Podskrift window; if it keeps bouncing, open Settings → Connected apps after logging in on the website, then try Connect again in ChatGPT.
  • Not available on your plan — Free and Go cannot add custom MCP servers. Pro has read/fetch; full MCP is a Business/Enterprise/Edu beta. If Add custom MCP server is missing, your account cannot add one yet.
  • Revoke access — On Podskrift, go to Settings → Connected apps and revoke ChatGPT. You can reconnect later.
