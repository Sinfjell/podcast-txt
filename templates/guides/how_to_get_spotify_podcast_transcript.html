Where is the transcript on iPhone/Android?

  1. Play the episode

    Open the episode in the Spotify mobile app and start playback. Spotify says listeners see transcripts in the Now Playing View and on episode pages in the mobile app.

  2. Open full-screen Now Playing

    Tap the mini player at the bottom so the episode fills the screen.

  3. Scroll to Read Along

    Scroll down the Now Playing View to find the transcript, then tap the card to follow along full screen while the audio plays (Spotify’s newsroom calls this Read Along). On some app versions the card replaces the cover art; on others it sits under About this episode.

On desktop and the web player?

  1. Play the episode in the Spotify desktop app or at open.spotify.com.
  2. Open the Now Playing panel on the right (the control near the bottom-right of the player).
  3. Scroll that panel. Where a transcript exists, Read Along / Episode transcript appears there.

Spotify’s published help focuses on the mobile Now Playing View. Some auto-generated transcripts are available on mobile only. If you see one on your phone and nothing on desktop, that can be expected.

Why is there no transcript?

  • Eligibility — Spotify generates transcripts only for select shows, not the whole catalogue (the 2023 newsroom post described a rollout to millions of episodes, not every show).
  • Creator turned it off — in Spotify for Creators, publishers can disable transcripts per episode or for the whole show.
  • Desktop limits — not every transcript that appears on mobile is shown on desktop or the web player.
  • App version — older clients may hide the control; update Spotify and try again before concluding there is none.

Can you copy or download it?

Spotify’s Read Along text is for following along in the app. Listeners cannot select the full transcript, download .txt or .srt, or export it into another tool. Spotify’s download and upload tools are for creators in Spotify for Creators (VTT/SRT for their own eligible episodes), not for listeners.

Creators with access to Spotify for Creators can view, download or upload transcripts for their own eligible episodes — that path is for show owners, not listeners. See Managing episode transcripts on Spotify.

How to download a Spotify podcast transcript as a text file

  1. Copy the episode link from Spotify (Share → Copy link). It should start with open.spotify.com/episode/. A show link works too.
  2. Paste it into Podskrift’s Spotify transcript page.
  3. Confirm the matched episode from the show’s public RSS feed, then start transcription.
  4. When it finishes, copy the text or download .txt and .srt.

Limits: only episodes that also appear in a public feed. Spotify exclusives, Originals and subscriber-only episodes without a public RSS feed have no audio Podskrift can fetch — see Spotify episode without RSS. This still works when Spotify shows no Read Along, as long as a public feed exists — Spotify transcript not available.

Check the show’s RSS feed for a ready-made transcript

Some podcast hosts publish a ready-made transcript in the show’s public RSS feed using the Podcasting 2.0 podcast:transcript tag. That tag links to a transcript or captions file (often VTT or SRT; plain text and other types are allowed too). Multiple tags can appear for multiple formats. See the Podcasting 2.0 docs and the podcast:transcript tag.

Spotify for Creators can also distribute creator transcripts across other platforms via RSS when the creator turns that setting on. If the host already publishes a file, download that before re-transcribing. Need the feed URL? See how to find an RSS feed.
